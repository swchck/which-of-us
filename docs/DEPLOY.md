# Веб-версия на своём домене

В этом режиме игра работает без установки и без общей Wi-Fi сети. Телевизор открывает
`https://ваш-домен`, гости заходят с телефонов через мобильный интернет. Всё работает в одном
контейнере: экран ТВ, страница телефона и игровой сервер.

## Что нужно от вас

- **Хостинг для контейнера.** Подойдёт любой с поддержкой WebSocket и HTTPS: Fly.io, Render,
  Railway, свой VPS с Caddy или nginx. Достаточно минимального тарифа: на 8 телефонах сервер
  отвечает быстрее чем за 1 мс (см. `npm run load`).
- **Домен** (необязательно): у Fly.io и Render есть свой адрес вида `*.fly.dev`.

## Переменные окружения

| Переменная | Значение |
| --- | --- |
| `PUBLIC_URL` | адрес, который открывают люди, например `https://party.example.com`. Без него QR в лобби указывает на внутренний IP контейнера |
| `PORT` | порт внутри контейнера, по умолчанию `8080` |
| `KTO_DATA_DIR` | куда сохранять комнаты, по умолчанию `/data`. Подключите сюда диск, тогда перезапуск не выкинет игроков из лобби |

При заданном `PUBLIC_URL`:
- сервер не поднимает свой HTTPS-порт — шифрованием занимается прокси хостинга;
- датчики наклона на телефонах работают сразу, потому что страница открыта по HTTPS.

## Fly.io

```bash
fly launch --no-deploy
```

```bash
fly volumes create kto_data --size 1
```

В `fly.toml` добавьте:

```toml
[env]
  PUBLIC_URL = "https://<имя-приложения>.fly.dev"

[mounts]
  source = "kto_data"
  destination = "/data"

[http_service]
  internal_port = 8080
```

```bash
fly deploy
```

## Свой сервер

```bash
docker build -t kto-iz-nas .
```

```bash
docker run -d --restart unless-stopped -p 8080:8080 -v kto-data:/data -e PUBLIC_URL=https://party.example.com kto-iz-nas
```

Перед контейнером нужен прокси с HTTPS. С Caddy достаточно двух строк в `Caddyfile`:

```
party.example.com {
  reverse_proxy localhost:8080
}
```

## Защита

Код комнаты — 4 цифры, поэтому в интернете его можно подобрать. Сервер даёт одному адресу
не больше 20 неверных кодов в минуту, а затем отвечает «Слишком много попыток». Комнат на сервер —
не больше 500. Ведущий может убрать из лобби любого, кто зашёл без приглашения: крестик у игрока
на экране ТВ.
