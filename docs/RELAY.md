# Игра через интернет (релей)

Игра остаётся на компьютере. Сервер, озвучка и комнаты работают как раньше, а телефоны заходят
по постоянному HTTPS-адресу из любой сети. Между ними стоит маленький релей на Cloudflare
Workers (`relay/`, Rust). Компьютер сам открывает к нему исходящее соединение, поэтому NAT и
роутер не мешают, а пробрасывать порты не нужно. Устройство и принятые решения описаны в
[docs/design/internet-relay.md](design/internet-relay.md).

Режим по Wi-Fi остаётся по умолчанию. «Через интернет» включается в настройках на ТВ, в
разделе «Подключение телефонов», и действует для этой комнаты. После перезапуска приложения
комнаты возвращаются в режим Wi-Fi, и интернет нужно включить снова.

## Что нужно один раз

- Аккаунт Cloudflare. Хватит бесплатного плана.
- Rust через rustup с целью wasm и сборщиком воркеров:

  ```bash
  rustup target add wasm32-unknown-unknown
  ```

  ```bash
  cargo install worker-build
  ```

  Если `cargo` от Homebrew стоит раньше в `PATH`, скрипты всё равно берут rustup-версию из
  `~/.cargo/bin`.

## Развернуть релей

```bash
npx wrangler login
```

```bash
npm run relay:deploy
```

Wrangler напечатает адрес вида `https://kto-relay.<аккаунт>.workers.dev`. Повторный деплой
адрес не меняет, а занятые коды хостов сохраняются.

## Адрес в приложении

Приложение по умолчанию ходит на `https://kto-relay.swchck.workers.dev`. Адрес задан
константой `DEFAULT_RELAY_URL` в `desktop/src-tauri/src/lib.rs`. Другой адрес задаётся при
сборке DMG:

```bash
KTO_RELAY_URL=https://kto-relay.<аккаунт>.workers.dev npm run desktop:build
```

С пустым `KTO_RELAY_URL=` приложение собирается без переключателя «Через интернет». При
запуске сервера из терминала (`npm start`) адрес задаётся той же переменной окружения, а без неё
переключатель не появляется.

## Проверить локально

В одном терминале запустите релей на `http://127.0.0.1:8787`:

```bash
npm run relay:dev
```

В другом запустите игру с этим адресом:

```bash
KTO_RELAY_URL=http://127.0.0.1:8787 npm start
```

На ТВ включите «Через интернет» и откройте с этого же компьютера ссылку под QR.

Тесты:
- `npm run relay:test` — кодек кадров, правила путей и clippy для релея;
- `npx vitest run tests/relay.test.ts tests/tunnel.test.ts` — сторона компьютера с фейковым
  релеем.

## Как это работает для игрока

1. QR на ТВ ведёт на `https://<релей>/<код компьютера>?c=<комната>`.
2. Релей ставит cookie с кодом компьютера и отправляет на `/p?c=<комната>`. Дальше страница,
   картинки, WebSocket и загрузка фото идут через туннель к компьютеру.
3. Если компьютер не в сети, телефон видит страницу «Компьютер с игрой не в сети». Она
   обновляется сама каждые 5 секунд.

Код компьютера (8 символов) и его секрет лежат в папке данных приложения, в файле
`relay.json`. Поэтому ссылка постоянная для этой установки. Если файл удалить, при следующем
включении появится новый код. Старый освободится сам через 60 дней.

## Что телефон через релей не может

- Открыть экран ТВ, озвучку, логи и `/api/info`: релей пропускает только пути страницы игрока.
- Создать комнату или стать ведущим: такие сообщения от телефонов через релей игнорируются.
- Занять место отключившегося игрока, просто назвавшись его именем: нужен токен этого
  телефона, как и в онлайн-режиме.

## Лимиты бесплатного плана

Главный лимит — 13 000 ГБ·с в сутки времени работы Durable Object. Это примерно 14
двухчасовых партий в сутки на всех, кто пользуется этим релеем. Если упрётесь, план Workers
Paid ($5 в месяц) снимает вопрос. Посмотреть, что происходит, можно командой
`npx wrangler tail` в папке `relay/` или в разделе Workers Logs панели Cloudflare.
