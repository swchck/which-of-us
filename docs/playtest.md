# Live playtest checklist

The automated tests drive Chrome. Real phones differ: Safari's keyboard, iOS permission prompts,
a cheap Android under load, a TV across the room. Run this before a release, on at least one
iPhone, one Android, and the desktop app on the TV.

## Setup

- [ ] Desktop app starts, QR code opens the join page on both phones over Wi-Fi.
- [ ] Phone joins with name and colour; renaming from the lobby works; selfie and retake work.
- [ ] A third phone joining mid-game becomes audience and gets a seat in the next game.
- [ ] Setup panel: catalogs for games and places open, NEW stickers show, toggles stick.
- [ ] Two people alone: the shared «Вместе» score shows on the rail and at the final.
- [ ] Team mode with four or more: two teams on the rail, scores table and final.

## Every game, once

- [ ] Rules screen readable from the sofa; «Понятно» on phones skips ahead.
- [ ] The narrator finishes every line before the phase moves on.
- [ ] Phone screens fit without sideways scrolling, with the keyboard open where there is typing.
- [ ] Arena games («Звездопад», «Сумо», «Квач»): joystick feels direct, no lag spikes on the TV.
- [ ] «Замри!»: the pause is audible on the TV; a finger left on the glass gets caught.
- [ ] «Перетягивание каната», «Тапалка»: rapid taps register, nothing zooms or selects text.

## Scoring

- [ ] Joker: button shows on «Кто из нас?» and «Угадай ответ», doubles the points, count drops.
- [ ] Everyone voting alike gives everyone a joker and the reveal says so.
- [ ] The score rail matches the scores table after each round.

## Endings

- [ ] Final: podium, awards, best moments and drawings cycle on the TV.
- [ ] Phone album saves a picture and the whole collage, through the share sheet on iOS.
- [ ] «Сыграть ещё!» starts a new game with the same people.

## Room for error

- [ ] Phone locks mid-question and comes back: it rejoins the same seat.
- [ ] TV reloads mid-game: the game picks up where it was.
- [ ] Pause → «Что-то пошло не так» saves a report folder; the path is shown on the TV.
- [ ] The Mac does not sleep during a long game; the phone screen stays on in arena games.
